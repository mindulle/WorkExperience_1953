# 디자인 프로토타입 (Design Prototypes)

팀원이 전달한 HTML 프로토타입 원본입니다. 대시보드 UI 구현의 **시각 규격 기준**으로 삼습니다.

## 파일

| 파일 | 내용 |
|---|---|
| `wave-and-vibe-console.html` | v1. 6개 뷰 전체 (대시보드 · 리뷰 탐색 · 트렌드 분석 · 지점 관리 · 고객 세그먼트 · AI 추천), 카드 26장 |
| `wave-and-vibe-console-v2.html` | **현재 기준 문서(v2).** 6주차 회의 수정안(#124) — 트렌드 분석 뷰 제거, AI Admin UI 추가 등 v1 대비 구조 변경 반영. Storybook `ConsoleV2` 스토리로 열람 |

## 열람 방법

Storybook의 `Reference/프로토타입` 스토리에서 볼 수 있습니다.

```bash
cd src/web && npm run storybook
```

`.storybook/main.ts`의 `staticDirs`가 이 디렉토리를 `/design`으로 서빙합니다. `public/`이 아니라 `docs/`에 있으므로 **배포물(`out/`)에는 포함되지 않습니다.**

## ⚠️ 프로토타입의 데이터는 데모입니다

프로토타입 수치를 그대로 구현하면 안 됩니다. 실제 파이프라인이 수집하는 데이터와 다르며, 일부는 수집이 **금지**되어 있습니다.

| 프로토타입 | 실제 |
|---|---|
| 리뷰 3,428건 / 5지점 | **6지점** (`docs/review-data-schema.md` 공식 지점명 참고). 리뷰 총건수는 더 이상 고정 목표치가 아니라 파이프라인 재실행마다 달라짐 — RULES §2.3 참고 |
| 평균 평점 4.3 / 5.0 | 파이프라인에 평점 수집 코드 없음 |
| 채널: 네이버·카카오·구글·배달앱 | (2026-07-29 개정) 네이버·유튜브에 더해 구글맵·캐치테이블 등 공개 리뷰 페이지 열람도 허용 (RULES §2.1). 실제로는 네이버(블로그/카페/뉴스) + 유튜브 + 네이버 플레이스 영수증 + 카카오맵까지 수집 중 |
| 12주 주간 추이 | 네이버 카페는 작성일 결측이라 추이 분석에서 제외 (§2.2 R2) |
| 시간대 분석 (점심 피크) | 방문 시간 데이터 미수집 |
| 지점명: 서면본점·해운대점 등 | 공식 지점명 6개: 광안점·사직점·서면점·본점·BIFC문현점·중앙동점(`docs/review-data-schema.md` 참고). ⚠️ 단, 이 정규화는 `merge_team_data.py`(현재 최종 산출 경로에서 안 쓰임)에만 구현돼 있어, 실제 최종 데이터(`정제_리뷰데이터` 탭)에는 원본 수집 표기(경성대본점·광안리점·부산역점 등)가 그대로 남아있을 수 있음 |

데이터가 없는 카드는 플레이스홀더로 두고, 파이프라인이 채워질 때마다 구현합니다.
