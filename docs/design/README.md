# 디자인 프로토타입 (Design Prototypes)

팀원이 전달한 HTML 프로토타입 원본입니다. 대시보드 UI 구현의 **시각 규격 기준**으로 삼습니다.

## 파일

| 파일 | 내용 |
|---|---|
| `wave-and-vibe-console.html` | **기준 문서.** 6개 뷰 전체 (대시보드 · 리뷰 탐색 · 트렌드 분석 · 지점 관리 · 고객 세그먼트 · AI 추천), 카드 26장 |

## 열람 방법

Storybook의 `Reference/프로토타입` 스토리에서 볼 수 있습니다.

```bash
cd src/web && npm run storybook
```

`.storybook/main.ts`의 `staticDirs`가 이 디렉토리를 `/design`으로 서빙합니다. `public/`이 아니라 `docs/`에 있으므로 **배포물(`out/`)에는 포함되지 않습니다.**

## ⚠️ 프로토타입의 데이터는 데모입니다

프로토타입 수치를 그대로 구현하면 안 됩니다. 실제 파이프라인이 수집하는 데이터와 다르며, 일부는 수집이 **금지**되어 있습니다.

| 프로토타입 | 실제 |
|---|---|
| 리뷰 3,428건 / 5지점 | **1,716건 / 2지점** (RULES §2.3 기준값 — 채널 제한 완화로 갱신 필요, 아래 참고) |
| 평균 평점 4.3 / 5.0 | 파이프라인에 평점 수집 코드 없음 |
| 채널: 네이버·카카오·구글·배달앱 | (2026-07-29 개정) 네이버·유튜브에 더해 구글맵·캐치테이블 등 공개 리뷰 페이지 열람도 허용 (RULES §2.1) |
| 12주 주간 추이 | 네이버 카페는 작성일 결측이라 추이 분석에서 제외 (§2.2 R2) |
| 시간대 분석 (점심 피크) | 방문 시간 데이터 미수집 |
| 지점명: 서면본점·해운대점 등 | 경성대본점·광안점 |

데이터가 없는 카드는 플레이스홀더로 두고, 파이프라인이 채워질 때마다 구현합니다.

> ⚠️ **1,716건/2지점 수치는 채널 제한이 있던 시점 기준이라 곧 갱신이 필요합니다.** 구글맵·캐치테이블 등 새 채널로 수집된 리뷰 데이터(카카오톡으로 팀원들이 전달, 이슈 #66 참고)가 반영되면 이 표와 `clean_mentions.py`의 검증 기준(RULES §2.3)을 함께 업데이트하세요.

## 토큰 정합 현황

`src/web/app/globals.css`와 프로토타입의 CSS 변수가 **아직 일치하지 않습니다.**

- **프로토타입에 있으나 미반영** — `--brand`, `--s-blue`, `--s-blue-soft`, `--grid`
- **프로토타입에 없으나 코드가 생성** — `--primary`, `--primary-soft`

현재 `Button`이 쓰는 `--primary`는 프로토타입에 없는 토큰입니다. 프로토타입은 `--brand` / `--s-blue` 계열을 사용합니다. 정합 작업과 자동 검증 테스트는 별도 이슈에서 다룹니다.
